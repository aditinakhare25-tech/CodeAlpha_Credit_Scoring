#CodeAlpha Credit Scoring Model

## Internship 
CodeAlpha Machine Learning Internship

## Project
Credit Scoring Model

## Description 
This project predicts whether a credit card customer is likely to default on their payment using Machine learning.

## Algorithm
Logistic Regression

## Feature Engineering
An average payment-status feature was created using the customer's payment status history.

## Evaluation
The model was evaluated using:
- Precision
- Recall
- F1-Score
- ROC-AUC
- Confusion matrix
- ROC curve

## Tools and technologies
- Python
- Pandas
- Numpy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Dataset
Default of credit card clients dataset.
